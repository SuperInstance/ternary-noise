# ternary-noise

Noise resilience analysis for ternary {-1, 0, +1} agent systems. Models Gaussian, uniform, impulse, and structured noise; finds the conservation-breaking SNR breakpoint via binary search; provides denoising via majority/median filters.

## Why It Matters

Every real-world ternary system — whether it's a BitNet neural network, a population genetics model, or a distributed consensus protocol — faces noise. The critical question: *how much noise can a ternary system tolerate before its conservation laws break?*

This crate provides the experimental framework to answer that question rigorously:

- **Noise injection** at controlled SNR levels (dB)
- **Conservation monitoring**: track sum, energy, and sign-balance invariants
- **Breakpoint detection**: binary search for the exact SNR where invariants fail
- **Tolerance profiling**: sweep SNR to build fitness-vs-noise curves
- **Denoising**: majority and median filters to recover clean signals

## How It Works

### Noise Models

All noise is generated by a seedable xorshift64 PRNG — zero external dependencies.

| Model | Distribution | PDF | Use Case |
|---|---|---|---|
| Gaussian | $\mathcal{N}(0, \sigma^2)$, clamped to [-1, 1] | $p(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-x^2/2\sigma^2}$ | Thermal noise, quantization error |
| Uniform | $\mathcal{U}(-s, +s)$ | $p(x) = 1/(2s)$ | Random bit flips |
| Impulse | Bernoulli: 0 with prob $1-p$, ±1 with prob $p/2$ each | $p(x) = (1-p)\delta(x) + \frac{p}{2}[\delta(x+1)+\delta(x-1)]$ | Sensor spikes, packet loss |
| Structured | Block-correlated uniform over correlation length $L$ | Block-constant noise | Spatial/systematic bias |

### SNR Calibration

Noise strength $\sigma$ is derived from target SNR:

$$\sigma = \frac{1}{\sqrt{\text{SNR}_{\text{linear}}}} = 10^{-\text{SNR}_{\text{dB}}/20}$$

At 0 dB, $\sigma = 1.0$ (signal and noise have equal power). At 40 dB, $\sigma \approx 0.01$.

**Perturbation of ternary value $t$:**

$$t' = \text{clamp}\!\left(\text{round}(t + 3\sigma \cdot n),\;-1,\;+1\right)$$

where $n$ is drawn from the chosen noise distribution.

### Conservation Laws

For a ternary vector $\mathbf{x} \in \{-1,0,+1\}^n$:

- **Sum:** $S = \sum_i x_i$
- **Energy:** $E = \sum_i |x_i|$
- **Sign balance:** ratio $|\{i: x_i = +1\}| / |\{i: x_i \neq 0\}|$

A conservation law holds within tolerance $\epsilon$ if $|S_{\text{noisy}} - S_{\text{clean}}| \leq \epsilon \cdot E_{\text{clean}}$.

### Breakpoint Detection

Binary search over SNR ∈ [-40, +60] dB. At each step:
1. Inject noise at midpoint SNR
2. Check all conservation laws
3. If conserved: search lower (push toward failure)
4. If broken: search higher (find the boundary)

**Complexity:** $O(n \log(\text{SNR range}))$ — 50 iterations suffice for < 0.1 dB precision.

### Denoising

- **Majority filter** (window $w$): replace each element with the most common value in its window. Removes impulse noise. O($n \cdot w$).
- **Median filter**: replace with the median of the window. Preserves edges better. O($n \cdot w \log w$).
- **Multi-pass**: apply majority filter $k$ times for progressively smoother output.

## Quick Start

```rust
use ternary_noise::*;

let clean: Vec<Ternary> = (0..100).map(|i| match i % 3 {
    0 => Ternary::Neg, 1 => Ternary::Zero, _ => Ternary::Pos
}).collect();

// Find conservation breakpoint
let bp = ConservationBreakpoint::find(&clean, NoiseModelType::Gaussian, 0.1);
println!("Breaks at {:.1} dB SNR", bp);

// Tolerance sweep
let results = NoiseToleranceTest::sweep(&clean, NoiseModelType::Uniform, 30.0, -10.0, 20, 42);

// Denoise
let mut noisy_env = NoisyEnvironment::new(NoiseModel::impulse(42, 0.2), 10.0);
let noisy = noisy_env.inject(&clean);
let denoised = DenoisingStrategy::majority_filter(&noisy, 3);

// SNR metrics
let snr = SignalToNoise::measure(&clean, &denoised);
let psnr = SignalToNoise::psnr(&clean, &noisy);
```

## Architecture Notes

Noise directly attacks the **γ + η = C** conservation identity. Gaussian noise randomly converts between γ (positive), η (negative), and neutral populations — at low SNR, the conversion rate exceeds the system's ability to maintain the conserved total $C$. The breakpoint SNR is the critical noise level where the conservation law transitions from holding (ordered regime) to failing (disordered regime).

The impulse model is the most destructive per-decibel because it directly injects ±1 values that maximize $|t' - t|$. Structured noise is insidious because correlated blocks can shift the sign balance without triggering sum-conservation violations.
